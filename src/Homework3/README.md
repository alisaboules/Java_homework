## Консольное приложение для работы с CSV и XML файлами

### Описание проекта

Консольное приложение для чтения файлов-справочников городов в форматах CSV и XML и формирования статистики по содержащимся в них адресам.

Программа поддерживает оба формата файлов и использует общий интерфейс парсера, что позволяет выбирать способ чтения файла в зависимости от его расширения.

### Структура проекта

| Класс | Назначение |
|---|---|
| `Main` | Точка входа в приложение. Запускает программу. |
| `ConsoleApp` | Обеспечивает взаимодействие с пользователем, принимает пути к файлам и команды завершения работы. |
| `Address` | Модель записи, содержащая информацию об адресе: город, улицу, номер дома и этажность. |
| `AddressParser` | Общий контракт для парсеров CSV и XML. |
| `CsvAddressParser` | Читает и разбирает файлы формата CSV. |
| `XmlAddressParser` | Читает и разбирает файлы формата XML. |
| `ParserFactory` | Выбирает подходящий парсер на основании расширения файла. |
| `StatisticsService` | Выполняет обработку полученных записей и формирует статистику. |

### Функциональность

Приложение позволяет:

- Загружать справочники адресов из CSV- и XML-файлов.
- Автоматически определять формат файла и выбирать соответствующий парсер.
- Находить дублирующиеся записи и отображать количество их повторений.
- Подсчитывать количество одно-, двух-, трёх-, четырёх- и пятиэтажных зданий в каждом городе.
- Измерять и отображать время обработки файла.
- Последовательно обрабатывать несколько файлов за один запуск программы.

### Принцип работы

1. После запуска приложение ожидает ввода пути к файлу или команды завершения работы.
2. Полученный путь передаётся в `ParserFactory`.
3. Фабрика определяет формат файла по расширению и создаёт соответствующий парсер.
4. Парсер считывает данные и преобразует их в объекты `Address`.
5. Полученные записи передаются в `StatisticsService`.
6. Сервис формирует статистику, которая выводится пользователю через `ConsoleApp`.
7. После завершения обработки приложение снова ожидает ввод следующего пути или команды завершения.

### Используемые технологии

- Java
- XML
- CSV
- Объектно-ориентированное программирование (ООП)

### Запуск приложения

Запустите класс `Main` из среды разработки или скомпилируйте проект и запустите приложение из командной строки.

### Входные данные

Программа принимает файлы-справочники в двух форматах:

- `.csv`
- `.xml`

Каждая запись содержит город, улицу, номер дома и количество этажей.
