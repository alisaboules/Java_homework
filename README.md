# Java OOP Homework 📚

Репозиторий для практических работ по курсу **"Объектно-ориентированное программирование"** (2 курс).

## 📋 О репозитории

Здесь собраны решения четырёх практических заданий по Java. На данный момент готовы **2 из 4** работ.

## ✅ Готовые работы

### 1. Консольный симулятор службы доставки 🚚
Моделирование работы небольшой службы доставки с возможностью:
- Создания заказов с несколькими позициями
- Выбора способа доставки (стандартная, экспресс, самовывоз)
- Назначения курьера
- Отслеживания статусов заказа

**Ключевые принципы:** инкапсуляция, композиция, полиморфизм через интерфейс `DeliveryMethod`.

### 2. Консольный поиск по Википедии 🔍
Программа для поиска статей в Википедии с консоли:
- Ввод поискового запроса и вывод результатов
- Открытие выбранной статьи в браузере
- Работа с Wikipedia API без сторонних библиотек (кроме Gson)
- Корректная обработка ошибок сети и пользовательского ввода

**Ключевые принципы:** разделение ответственности (ввод, API, парсинг, вывод), обработка исключений.
